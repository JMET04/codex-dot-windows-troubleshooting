## 代理证据的边界

只读检查当前安装包的静态连接工厂：公开 durable 云端 WebSocket 分支不选择 Windows 系统代理或显式 SOCKS 代理。因此回环代理上的 TLS 超时不能单独解释这条原生连接的 HTTP 403。无显式代理的请求仍可能经过操作系统隧道或上游转发，不能称为已验证的物理直连。

没有修改官方应用包、关闭证书校验、复制登录头或自行重放认证请求。此前匿名 HTTP、TLS 与隧道试验保留在 [网络路径记录](runtime-network-routing.md) 与 [TLS 记录](tls-and-tunnel-routing.md)，均不等于原生业务验收。
