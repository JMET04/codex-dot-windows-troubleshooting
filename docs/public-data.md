# 公开数据与包内容

本包采用明确文件清单重新整理，未整体复制原通道目录。

未公开：私人聊天内容与截图、账号邮箱与设备名、用户配置及配置备份、认证文件、秘密目录、电脑用户名与真实绝对目录、真实聊天/回合 ID、验证码和请求 ID、完整桌面日志、原始目标专用脚本、原技能私人数据库。

公开内容：

- 重新撰写的原因、步骤、回滚、限制和官方引用。
- 手工与程序对照原始记录后生成的实测摘要。脱敏摘要只保留版本、错误类别和已核对的布尔结论，不是原始接口响应，也不是外部独立审计。
- 明确标为 synthetic 的协议与回执演示。不把样例冒充新的测试结果。
- 新写的只读元数据探测和离线回执比较工具；没有私人路径、授权白名单或认证信息。

实际运行探测器会在你指定的本地报告中保存目标元数据，包括其名称、目录及 ID；不要未经检查上传报告。演示回执的比较只能检查字段一致，不能认证文件来源。

发布前对包文件及 ZIP 做个人标识、账号凭据形态和绝对个人路径检查；SHA-256 清单用于检测发布内容改变，不是真实性签名。
